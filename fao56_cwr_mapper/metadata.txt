name=FAO-56 Crop Water Requirement Mapper
qgisMinimumVersion=3.22
qgisMaximumVersion=4.99
description=Maps FAO-56 crop water requirement (ETo, ETc, effective rainfall, net irrigation) for fields and points from NASA POWER, Open-Meteo (ERA5) or weather station data.
about=Computes the FAO-56 crop water requirement chain for each field (polygon) or point: daily Penman-Monteith reference evapotranspiration ETo, single crop coefficient ETc = Kc x ETo with FAO-56 Table 11 stage lengths and Table 12 Kc values (checked against the printed publication), effective rainfall (fixed fraction or USDA SCS, CROPWAT form or NEH Part 623) and net irrigation requirement in mm and m3 per dekad (CROPWAT-like) or per day. Climate data: NASA POWER or Open-Meteo ERA5 reanalysis (downloaded automatically, no API key; the free Open-Meteo API is for non-commercial use only), or your own weather station CSV with a station point layer - nearest station or Thiessen area weighting, with the FAO-56 procedures for missing humidity, radiation and wind. Runs as a Processing algorithm (batch and Graphical Modeler), writes a styled result layer, optional daily/dekad CSV files and an HTML run report with method, data source, references and warnings. The calculation core is pure Python with unit tests against the FAO-56 worked examples. Experimental: no soil water balance is modelled yet; QGIS 4 support is declared but not yet tested on QGIS 4 - feedback is welcome.
